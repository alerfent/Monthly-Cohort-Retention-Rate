# Monthly-Cohort-Retention-Rate

##專案簡介
本專案透過Cohort Analysis(世代分析)方法，追蹤零售品牌在顧客首次購買後的留存與回購行為，
找出那些顧客世代、那些地區的留存表現較佳或較差，並嘗試分析背後可能的原因。

##背景與動機
我曾在餐飲零售業擔任店長與值班經理超過 6 年，第一線觀察到：每週總有固定的
客人回來消費，點的品項也往往和上一次相似；相對地，也有不少客人只出現過一次
就沒再回來。憑經驗判斷，熟客的回購頻率明顯高於一次性顧客，這也讓我體會到
「熟客經營」對品牌長期營運的重要性——但當時始終只能憑觀察與直覺判斷，
沒有系統化的方法去追蹤、驗證這個現象，也無法回答更進一步的問題：
不同時期加入的客群，留存表現是否有差異？哪些因素可能影響回購？

這個專案希望補上當時缺少的那塊：透過建立完整的資料工程流程（Data Pipeline），
將原始交易資料轉換為可驗證的顧客留存分析結果，用系統化的方法回答一個
我過去只能憑經驗回答的問題。

##分析問題與假設
**核心問題:**新客在首購後留存/回購率，如何隨著時間變化?
那些地區的留存表現特別突出或特別差?

##假設:**越晚加入的顧客世代，3個月留存率會低於越早加入的世代，
可能反映品牌近期的顧客黏著度下降。

##資料來源
- 資料集:[Online Retail II](https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci)（UCI / Kaggle 公開資料集)
- 規模:約100萬筆交易紀錄，時間範圍2009-2011年
- 主要欄位:CustomerID、InvoiceData、Country、Quantity、Price
